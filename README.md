# galaticos-api.github.io

Portfólio da equipe **Galáticos** (Galaticos-API), do curso de Análise e Desenvolvimento de Sistemas da Fatec Prof. Jessen Vidal, em São José dos Campos.

Site estático em HTML, CSS e JavaScript, sem build e sem dependências. As fontes vêm do Google Fonts.

## Rodar localmente

```bash
python -m http.server 8080
```

Abra http://localhost:8080.

## Publicar

Envie os arquivos para a branch `main` deste repositório e ative o GitHub Pages em Settings, Pages, "Deploy from a branch", `main` e pasta `/ (root)`.

## Atualizar o conteúdo

- Projetos: seção `#projetos` do `index.html`.
- Tripulação: seção `#equipe` do `index.html`.
- Órbitas do hero: lista `PROJECTS` em `assets/js/main.js`.
